# GuardianLink Backend API

Wearable tracker backend for special needs children who elope and adults with dementia.

## Quick Start

```bash
npm install
npm start
```

Server runs on `http://0.0.0.0:3001` by default.

## API Endpoints

### Auth
- `POST /auth/register` — Create caregiver account (`email`, `password`, `name`)
- `POST /auth/login` — Login (`email`, `password`) → returns JWT
- `GET /auth/me` — Get current user info (requires JWT)
- `POST /auth/generate-responder-key` — Generate responder API key (requires JWT)

### Patients
- `GET /patients` — List caregiver's patients (JWT)
- `POST /patients` — Create patient (JWT)
- `GET /patients/:id` — Get patient profile (JWT or responder key)
- `PUT /patients/:id` — Update patient (JWT, owner only)
- `DELETE /patients/:id` — Delete patient (JWT, owner only)
- `GET /patients/by-device/:serial` — **First responder endpoint**: get patient profile by tracker serial (responder key or JWT)

### Devices
- `GET /devices` — List all devices (JWT)
- `POST /devices/register` — Register a new tracker by serial number (JWT)
- `POST /devices/pair` — Pair tracker to patient (JWT)
- `POST /devices/unpair` — Unpair tracker from patient (JWT)
- `GET /devices/patient/:patientId` — List devices for a specific patient (JWT)

### Access Logs (KPI Tracking)
- `POST /access-logs` — Log a responder access (JWT)
- `GET /access-logs` — List access logs (JWT)
- `GET /access-logs/stats` — Aggregated KPI stats (JWT)

### Health
- `GET /health` — Server health check

## Auth
- **Caregivers**: JWT tokens (returned from register/login)
- **First Responders**: Pre-shared API keys (`gl_responder_...`) — generated by caregivers via `/auth/generate-responder-key`

Send as: `Authorization: Bearer <token>`

## Frontend Integration
The frontend (served on port 3000) should proxy `/api` requests to this backend on port 3001. Example nginx/reverse-proxy config:

```
/api/* → http://localhost:3001/*
```

## Environment
| Variable | Default | Description |
|---|---|---|
| `PORT` | `3001` | Server port |
| `HOST` | `0.0.0.0` | Bind address |
| `JWT_SECRET` | `guardianlink-dev-secret-...` | JWT signing secret |
| `JWT_EXPIRES_IN` | `7d` | Token expiry |
| `GUARDIANLINK_DB_PATH` | `./data/guardianlink.db` | SQLite database path |
